# Engine Telemetry and Health Monitoring

This document details the design, technical implementation, and visualization of internal combustion engine (ICE) and fuel system telemetry within the Stork application.

---

## 1. Overview

The Engine Telemetry feature integrates real-time health diagnostics for aircraft propulsion systems. Telemetry packets generated by engine sensors are transmitted via a physical CAN bus, encapsulated using the **DroneCAN** protocol, bridged over UDP via Cannelloni, and parsed natively inside Stork. The decoded parameters are reactively propagated to settings-configured, customizable overlay widgets on the main map.

---

## 2. Key Components

### 2.1. DroneCAN Messages & Parsers

Three specialized DroneCAN messages are parsed using a custom little-endian bit-level reader `BitReader` within [lib/core/native/dronecan](../../lib/core/native/dronecan):

1.  **[StorkEngineRpm](../../lib/core/native/dronecan/stork_engine_rpm.dart) (ID: `20120`)**:
    *   Parses `stork.equipment.ice.EngineRPM`.
    *   Provides: `engineSpeedRpm`, `engineLoadPercent`, `throttlePositionPercent`, `state`, and `ecuIndex`.
2.  **[IceStatus](../../lib/core/native/dronecan/ice_status.dart) (ID: `1120`)**:
    *   Parses `uavcan.equipment.ice.reciprocating.Status`.
    *   Provides coolant temperature, oil pressure, oil temperature, fuel pressure, and fuel consumption rate.
    *   Supports multi-cylinder setups via a dynamic array of **[CylinderStatus](../../lib/core/native/dronecan/ice_status.dart#L13)** nodes, capturing individual cylinder head temperatures (CHT) and exhaust gas temperatures (EGT).
    *   Implements error evaluation (`hasError` and `errorDescription`) by bitmasking the raw 30-bit status flag register.
3.  **[FuelTankStatus](../../lib/core/native/dronecan/fuel_tank_status.dart) (ID: `1129`)**:
    *   Parses `uavcan.equipment.ice.FuelTankStatus`.
    *   Provides percent fuel remaining, volumetric remaining fuel (in cm³), and temperature.

Parser verification is backed by test suites in [test/core/native/dronecan](../../test/core/native/dronecan).

### 2.2. Telemetry Processing & Decay Safety

Incoming packets are processed through **[CannelloniService](../../lib/core/services/cannelloni_service_io.dart)** which triggers native FFI callbacks. The service then updates the reactive state via **[TelemetryNotifier](../../lib/features/telemetry/presentation/providers/telemetry_provider.dart)**.

#### Decay Timeout
Safety is critical in aviation; displaying stale sensor readings must be prevented. In [TelemetryNotifier](../../lib/features/telemetry/presentation/providers/telemetry_provider.dart), all incoming engine fields are wrapped in **`DecayableField`** instances with a default **1.5-second timeout**. If no updates are received within this window, the field value automatically decays to `null`.

#### Persistent Support State
To prevent UI elements from unexpectedly flashing or disappearing when a connection drops, Stork decouples sensor data from sensor presence:
*   When a sensor message is first received, the presence flags (e.g. `isEngineRpmSupported`, `isFuelSupported`) are set to `true` in **[TelemetryState](../../lib/features/telemetry/domain/models/telemetry_state.dart)**.
*   If a timeout occurs, the numerical value decays to `null`, but the support flag **remains `true`**.
*   This triggers the corresponding widget to remain visible on the overlay while rendering a prominent **red error outline** indicating signal loss.

### 2.3. User Configuration & Unit Conversions

The settings system integrates physical units of measurement and safety limits:

1.  **Enums for Measurement Units**:
    *   **[TemperatureUnit](../../lib/features/settings/domain/models/temperature_unit.dart)**: Supports Celsius (°C), Kelvin (K), and Fahrenheit (°F).
    *   **[PressureUnit](../../lib/features/settings/domain/models/pressure_unit.dart)**: Supports bar, psi, and kPa.
2.  **App Settings Configuration**:
    *   **[AppSettings](../../lib/features/settings/domain/models/app_settings.dart)** stores thresholds (min error, min warning, max warning, max error, inactive threshold) and max slider limits.
    *   Internal math operates in SI units (Kelvin, kPa, RPM), while **[AppSettingsNotifier](../../lib/features/settings/presentation/providers/settings_provider.dart)** automatically converts values to the selected user preferences.
3.  **UI Threshold Configuration**:
    *   In the **[FlightSettingsPage](../../lib/features/settings/presentation/pages/flight_settings_page.dart)**, users can drag multi-point sliders (**[ThresholdsSlider](../../lib/features/settings/presentation/widgets/thresholds_slider.dart)**) to configure safety thresholds for all motor metrics.

---

### 2.4. Overlay Visualization Widgets

Telemetry widgets are dynamically added to the **[MapPage](../../lib/features/map/presentation/pages/map_page.dart)** overlay based on active sensor support:

*   **[OilTempTelemetryWidget](../../lib/features/telemetry/presentation/widgets/oil_temp_telemetry_widget.dart)** & **[OilPressureTelemetryWidget](../../lib/features/telemetry/presentation/widgets/oil_pressure_telemetry_widget.dart)**: Single-indicator vertical gauges.
*   **[CylinderTempTelemetryWidget](../../lib/features/telemetry/presentation/widgets/cylinder_temp_telemetry_widget.dart)** (CHT) & **[EgtTelemetryWidget](../../lib/features/telemetry/presentation/widgets/egt_telemetry_widget.dart)** (EGT): Multi-cylinder vertical bars showing all cylinders simultaneously, automatically highlighting the hottest cylinder.
*   **[FuelStatusTelemetryWidget](../../lib/features/telemetry/presentation/widgets/fuel_status_telemetry_widget.dart)**: Displays fuel remaining in percent and volume, warning when thresholds are violated.
*   **[RpmHorizontalTelemetryWidget](../../lib/features/telemetry/presentation/widgets/rpm_horizontal_telemetry_widget.dart)**: A custom horizontal tachometer widget.

#### Custom Gauge Painters
*   **[SegmentedGaugePainter](../../lib/features/telemetry/presentation/widgets/segmented_gauge_painter.dart)** renders vertical glass-tube style indicators with custom backgrounds colored by thresholds (grey, red, orange, green, orange, red).
*   **HorizontalSegmentedGaugePainter** (defined in [rpm_horizontal_telemetry_widget.dart](../../lib/features/telemetry/presentation/widgets/rpm_horizontal_telemetry_widget.dart#L182)) renders the horizontal RPM gauge bar.

## 3. Testing and Verification

Verifying engine telemetry consists of unit and widget tests:

*   **Native DroneCAN Parsers**: Verified in [test/core/native/dronecan](../../test/core/native/dronecan).
*   **Timeout & Decay Safety**: Tested in [telemetry_timeout_test.dart](../../test/features/telemetry/presentation/providers/telemetry_timeout_test.dart) to ensure that the RPM decays after 1.5 seconds, while `isEngineRpmSupported` remains true.
*   **UI Telemetry Widgets**: Tested in [test/features/telemetry/presentation/widgets](../../test/features/telemetry/presentation/widgets) (e.g. CHT, EGT, oil temp widgets) to verify correct threshold coloring and error state transitions.
